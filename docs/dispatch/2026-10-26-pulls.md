## How to run it

- **One download at a time,** in a single queue run as a detached user unit (for example `forecast-pulls`), so it
  survives your session ending. Use `systemd-run --user -p MemoryMax=2G -p MemorySwapMax=0 -p Nice=10`, with the
  venv on the drive or under `/mnt/work/scratch/pulls/`. The queue resumes: a file whose checksum already matches
  is skipped, and a partial file is re-fetched, never trusted.
- **Each pull has a request record** in `docs/pulls/`, as earlier pulls do: URL, time, bytes and checksum.
- **The queue stops itself** on any checksum mismatch, a login wall, less than 20 GB free on the drive, or a
  `PAUSE` file at `forecast-data/PAUSE`. It logs the reason.
- t6b-night isn't running, and no fit runs alongside the queue.
