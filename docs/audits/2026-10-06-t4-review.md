### Check 8, the revert runs

The runner, for each check:
- runs the named test files forward and requires them green;
- saves the target file's bytes in memory, applies one exact edit (the anchor must occur once), and deletes every `__pycache__` outside `.venv`;
- sets `PYTHONDONTWRITEBYTECODE=1`;
- runs the tests with a fresh JUnit XML and a pytest plugin that evaluates a behaviour probe **inside the pytest interpreter**, from the loaded objects;
- restores from the saved bytes, never from git.

It refuses to cite a run if:
- the pytest exit code is not 0 or 1;
- the XML is missing or stale;
- the test count differs from the forward run;
- any test errors rather than fails;
- the probe output equals the forward probe's.

After all checks, every edited file is byte-identical to its saved copy, `git diff HEAD -- src scripts` is empty, and the reviewer's tests are present. **None of the five runs was refused.**
