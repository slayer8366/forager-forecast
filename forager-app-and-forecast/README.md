# Forager app and forecast: the shared history

Forager is a foraging app for Android (github.com/slayer8366/Forager). This repository, forager-forecast, builds the forecast the app and the website show. For a while both were planned in one place, so some of the records cover both at once. This folder keeps those together, so a reader of either project can find them without searching the other.

## What is here

- **`entries.md`:** 40 record entries that cover both projects, copied from Forager's record.
- **`preserved/`:** 13 dispatches and planner handoffs that cover both projects, copied from Forager's `prompts/preserved/`.
- **`docs/`:** 3 documents from Forager's `docs/`, kept at their original paths: a read of this repository's spec for the app's map layers, an app-code read about the app's forecast data, and the app's journal-redesign plan, which holds the map-layer rulings.

Everything here is a byte-for-byte copy of Forager at commit 35c14780 (branch records-after-173), and Forager keeps the originals. Some items are mostly about one project and mention the other in a line or two. They are here because the owner ruled that items on the boundary belong to both.

## Elsewhere in this repository

- `RECORD.md`: the forecast's own record, from 2026-09-28-2001 on.
- `records/from-forager.md`: the 213 earlier entries about the forecast alone.
- `docs/preserved/`: the 20 earlier dispatches about the forecast alone.

## Reading the copies

The copies are unchanged, so their references point into Forager. A bare ID such as "-1248" is an entry in Forager's RECORD.md, and a "preserved/…" path is in Forager's `prompts/preserved/`.
